# Visit Types

Choose the types of visit your team picks from when adding a visit to a booking, for example
"Drop off", "Collection" or "Visit at the customer's address". Each company has its own list.

**Bookings -> Settings -> Visit Types**, or navigate to `/admin/bookings/settings/visit-types`

---

## Built-in Types (the default)

Until your company adds its own types, **Add Visit** offers the built-in list:

- Initial Assessment
- Follow-up
- Repair Work
- Quality Check
- Delivery
- Other

Nothing changes for your company until you add a type of your own.

## Adding Your Own Types

Only **company admins** can change the list. Other team members can view it.

1. Type a name in the box at the top (e.g. "Collection from customer")
2. Click **Add visit type**

As soon as your company has **at least one active type of its own**, Add Visit offers **only your
types**, in your order. The built-in list is no longer offered.

### Managing the List

Each type has these controls:

- **Switch**: turn the type on or off. A switched-off type is hidden from Add Visit but stays in
  the list, so you can switch it back on
- **Up / Down arrows**: change the order the types appear in Add Visit
- **Pencil**: rename the type
- **Bin**: delete the type (you are asked to confirm)

If you switch **all** of your own types off, Add Visit goes back to the built-in list.

### Renaming or Deleting a Type

Renaming or deleting a type **never changes visits already booked**. They keep the type name they
were booked with.

## Where Visit Types Are Used

- **Booking -> Visits tab -> Add Visit**: the **Visit Type** dropdown offers your list (or the built-in
  one)
- Visits created **from the Scheduler** ("New Visit") have no type picker and no type; they show as
  **Appointment**
- Visits created by a **booking form** on your website are given **Initial Assessment**
  automatically

## Editing a Visit's Type

To change the type of a visit that is already booked, open the booking, go to the **Visits** tab and
click **Edit** on the visit. See [Booking Detail Page](13-booking-detail.md), Visits Tab.

---

## Common Questions

**We need a "Collection" type but Add Visit doesn't offer it.**
Add it in Bookings -> Settings -> Visit Types. Remember that once you add one type of your own, the
built-in ones are no longer offered, so add every type your team needs.

**I renamed a type but an old visit still shows the old name.**
That is expected: visits keep the name they were booked with.

**Can a non-admin add visit types?**
No. Only company admins can add, rename, reorder, switch off or delete types.
